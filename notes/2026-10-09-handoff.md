## 1. Decisions made by the maintainer

| Topic | Decision |
|---|---|
| Pipeline scope | Keep the pangenome and the pairwise pipelines. No family/HMM pathways (`mmseqs`, `novelty_discovery`; issue #219). Provisional upper bound 5,000 CPU-hours per run (issue #220 for a taxa bound). |
| Pair classification evidence | Representatives only for `n_co_carrying` and `linkage_fraction`. All strains build and draw islands. Near-identical strains can still carry islands that moved. |
| `trans` statistics | Full-precision `permutation_p` plus a BH `permutation_q` column. Gating on q is behind `--perm_correction` and is **off** by default. |
| Locus view | A column classifies strains only if its gene is in place in at least `min_column_strains` strains (default 2). A DNA-present gap is a "model difference" only if a gapped gene is in place in at least `model_diff_min_frac` (default 0.5) of strains; otherwise it is a "variable-gene gap". |
| Reference strains | Order of display strains. Afumigatus `Asfu_Af293,Asfu_A1163`. Cocci immitis-in `RS,WA_211` (proposed, not explicitly confirmed). Posadasii-in `B3245,COCPO_Galgiani` (maintainer changed from Silveira/C735-TKO). |

| Fusarium | No whole-FOXY or whole-FSSC pangenome (species mixture). `fusarium_FOXY_vs_FSSC` stays dropped. FOL, FSSC_solani, FSSC_ambrosia stay. Pairwise `fusarium_FOXY` may be rerun. |

| Cyanobacteria | Cap the ingroup at 8 genomes per genus (best N50): 212 IN + 60 OUT. |
| Publishing | `full_v072`, `immitis_in_posadasii_out_v4`, pezizo_set1 and agaricomycetes new runs are published. v071 and v3 are unpublished baselines. |

## 6. Procedures (tested this period)

**Relaunch a pangenome run under a new name and keep the cache.** See memory `ni-run-cache-carryover`. Copy `<old>/.nextflow`, symlink `<old>/work` (resolve to the real directory), copy `storedir_override.config` (points `MAKE_STRAIN_GENOME_DB` at the first run's `rescue/db`), launch with `bin/ni pangenome run --study-dir <study> --run <new> -- -c <override>`. Check `Cached` counts for `TBLASTN_PER_STRAIN` in the log. Never run two runs at once on one shared work directory.

**Pairwise rerun beside a published run.** Use a temporary project name (`<set>_main<sha>`), `-resume`, and a launch directory under `.nf_launch/<domain>/`. The head job script must run `nextflow pull -r <sha>` and `pixi install --frozen --manifest-path <clone>/pixi.toml` first. Do not reuse the pangenome `stajichlab_queue.config` (it overrides the tool environment).

**Stage a pairwise run.**
1. Move the old `results/<set>` aside; rename `results/<tmp>` and `docs/<tmp>` to the set name.
2. Set `studies/<domain>/<set>/publish.yaml` `run:` to a new label (for example `pairwise-diamond-very-sensitive`).
3. `NOVINVENIO_ROOT=<checkout with #233 and #234> bin/sync_reports.sh <domain>/<set>`.
4. If the temporary name remains in `report.html` (and, for studies without annotations, in `novelties.html`/`core.html`), replace it and update `report_sha256` in `run.json`.
5. `python bin/study_pages.py set-current <domain>/<study> <run>` makes it the current run.
6. Check every page: JSON payload valid (no `Infinity`/`NaN`) and loads in headless Chromium (`~/.cache/ms-playwright/chromium_headless_shell-*`). This caught two blank-page bugs.
7. `bin/publish_alignment_release.sh` and `bin/publish_report_release.sh <domain>/<set>/<run>`, then `git push`. A Pages deploy runs on push and on release.

For studies without annotations the core page comes from the pipeline output. Rebuild it with the current code if it predates #234.

**Rebuild `novelties.html` from fixed code** (used for agaricomycetes): copy the command from the `MAKE_REPORT_ONLINE` work directory's `.command.sh`, run `make_report.py` from a checkout with #233, with `--project <final name>`.
