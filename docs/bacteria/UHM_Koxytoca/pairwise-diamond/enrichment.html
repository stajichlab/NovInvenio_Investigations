UHM Koxytoca: functional enrichment (novelty)

One-sided hypergeometric test per term; Benjamini-Hochberg FDR within each scope, level and vocabulary. Candidates are the novelty candidates: gene families present in the IN group and absent from the OUT group. Universe: proteome. Background clustered: True (84356 sequences in 8840 clusters, mmseqs easy-cluster --min-seq-id 0.3 -c 0.8). Family level: one unit per candidate family and per background cluster.

Sources: Pfam: 2026-01-27-Pfam38.2; InterPro entries: 110.0; GO: releases/2026-07-26; analysis generated 2026-10-14T21:59:54. Source tables: studies/bacteria/UHM_Koxytoca/analysis/enrichment/outputs/proteome_clustered. Full record: PROVENANCE. Run report: report.html.

Caveats
  • Annotation: Pfam-A HMM search (hmmsearch, Pfam gathering thresholds) for every species; no UniProt annotation. Each annotation file has a provenance sidecar (domain table, HMMER version, Pfam release); PROVENANCE.yaml lists the files and their checksums.
  • GO: not available for this study (no GO annotation in any species).
  • Candidate families (pipeline clustering of candidates) and background clusters (mmseqs clustering of the background proteome) are made by different runs, so family-level counts are not fully comparable.
  • Low annotation: the candidate set has less than 50% annotation for Pfam 16.4%, any vocabulary 16.4%. Enrichment for these vocabularies has low power.
  • GO and InterPro: not available for this study. No species has GO and InterPro annotation (UHM102bin47, UHM125bin22, UHM125bin48, UHM145bin17, UHM145bin33, UHM145bin28, UHM17bin35, UHM18bin40, UHM20bin40, UHM20bin12, UHM22bin50, UHM22bin54, UHM22bin8, UHM40bin4, UHM40bin27, UHM43bin53, UHM56bin19, UHM72bin19), so no GO and InterPro test was run.
